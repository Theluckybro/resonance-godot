# Game Portfolio – Resonance (CV Summary)

**Project Title:** Resonance  
**Role:** Game Designer & Programmer  
**Engine:** Godot 4.x  
**Genre:** 2D Top-Down Action Roguelite  
**Platform:** PC (Windows, Linux)  
**Status:** In Development (Early Prototype, March 2026)

---

## Project Overview
Resonance is a 2D top-down action roguelite focused on fast-paced, modular combat. The core mechanic is the Vestige system, where players absorb abilities from defeated monsters and equip them as active skills or dash modifiers. The game emphasizes adaptability, tactical decision-making, and replayability through room-based progression.

## Key Responsibilities
- Designed and implemented the core gameplay loop (combat, Vestige absorption, room progression)
- Developed modular scene architecture for scalable content
- Created and maintained technical documentation (GDD, asset checklist, input/collision setup)
- Managed MVP scope, prioritizing essential features for rapid prototyping
- Balanced enemy archetypes and Vestige abilities using data-driven design

## Technical Highlights
- Godot 4.x scripting (GDScript), scene system, and autoloads
- Data-driven balancing for enemies and skills
- Custom input mapping and collision layer setup
- Pixel art pipeline integration for character and environment assets
- Iterative development with playtest-driven feedback

## Achievements (Prototype Stage)
- Playable core combat: movement, dash, basic attack, and damage flow
- Modular Vestige system: equip, swap, and activate monster abilities
- Room-based progression with increasing challenge
- Documented production workflow and asset requirements
